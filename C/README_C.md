# C 语言卡片导航

> **标准基准**：`C17`（ISO/IEC 9899:2018）。最低门槛 `C11` —— C17 与 C11 在语言层面完全等价，
> 只有缺陷修订，所以"C17 卡片"里的每一条语法在 C11 编译器上同样成立。
> C23 的新特性与 GNU 扩展见「附 · 查阅型 Block」。
>
> **工具链**：统一 gcc。Windows 开发主线是 WSL + gcc，不用 MinGW-w64。
> 所有示例在 gcc 默认参数下可直接编译运行。
>
> **怎么用**：本导航是 C 语言全部卡片的**唯一入口**，编号由本页维护。
> 每张卡 ≤ 5 分钟。`[ ]` 复选框**由你自己勾** —— 只有你勾过的卡片才会被撰写。

## 学习阶段

C 语言没有面向对象，因此本语言按「面向过程 → 面向函数 → 面向对象」三阶段递进组织，
阶段三以 C 自己的**等价惯用法**承载：

| 分组 | 对应阶段 | 目标 |
|------|---------|------|
| 阶段一 · 面向过程 | 面向过程 | 流程控制、错误处理、调用常用函数 —— 能写出一个结构清晰、会查手册、错误处理得当的 C 程序 |
| 阶段二 · 面向函数 | 面向函数 | 函数封装、传参、作用域、闭包、匿名函数 —— 能把行为封装成可复用、可组合、可传递的单元 |
| 阶段三 · 面向对象（C 的等价惯用法） | 面向对象（C 的等价惯用法） | C 没有 class，用 struct + 函数 + 不透明指针实现同样的效果 —— 读得出真实项目里的面向对象式 C 代码 |
| 附 · 查阅型 | —（参考材料，不参与阶段递进） | 标准版本对照与编译器扩展，用到时回来查 |

共 **16 个 Block / 140 张卡片**。
