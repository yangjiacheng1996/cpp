### 关于口径 6：三阶段学习模型（本轮核心变更）

一门编程语言的学习，按作者（Python 专家）的经验可分成三个阶段：

| 阶段 | 核心内容 | 在 Python 里 | 在 C++ 里 |
|------|---------|------------|-----------|
| **一 · 面向过程** | 流程控制、错误处理、调用常用函数 | `if`/`for`/`while`、`try/except`、内置函数 | 同左 |
| **二 · 面向函数** | 函数封装、传参、作用域、闭包、匿名函数 | `def`、`*args/**kwargs`、`global/nonlocal`、`lambda` | 同左 + 模板、lambda 表达式 |
| **三 · 面向对象** | 类、方法、元类 | `class`、`self`、`__init__`、元类 | `class`、继承、虚函数、模板元编程 |

**C 语言没有面向对象，所以 C 的学习路径只有前两个阶段。** 但 C 有一整套
"用结构体和函数模拟对象"的惯用法（Linux 内核的 `struct file_operations` 就是典型），
它是通往 C++ 的桥，因此以**阶段三的等价惯用法**形式保留。

由此产生 Block 排序的两条硬规则：

1. **Block MUST 按阶段分组**，导航页 MUST 用 `## 阶段一 · 面向过程` 这样的二级标题分组；
2. **同一阶段内 MUST 按依赖关系排列**（指针必须在内存管理之前，函数必须在回调之前）。

## 二、标准版本基准：C17

### 结论

- **基准标准：`C17`（ISO/IEC 9899:2018）**
- **最低门槛：`C11`** —— C17 相对 C11 没有新增任何语言特性，只有缺陷修订，
  所以"C17 教程"读到的每一条语法在 C11 编译器上同样成立。
- **向前看：`C23`（ISO/IEC 9899:2024）** —— 放在查阅型 Block（B16）承载，作为"高版本挂载卡"。
- **超出现标准的部分：GNU 扩展与编译器内建** —— 同样放 B16。Linux 内核、嵌入式、
  大部分开源 C 项目都在用，**不会用就读不懂真实代码**，与本项目目标直接相关。

### 为什么是 C17 而不是别的

| 候选 | 为什么不选 / 为什么选 |
|------|----------------------|
| **C89/C90** | ❌ 已死。`//` 注释、`long long`、for 循环内声明、VLA、`inline`、`restrict` 全都没有。Linux 内核早已跨过这个限制 |
| **C99** | ⚠️ 太旧。缺少 `_Generic`、`_Static_assert`、`_Alignas`、匿名结构体、线程局部存储 —— 而这些是现代代码的日常 |
| **C11** | ⚠️ 语言层面与 C17 **完全等价**（C17 = C11 + DR 修订）。选 C17 只是因为它更新的正式标准名，且 POSIX.1-2024（Issue 8）已对齐 C17 |
| **C17** | ✅ **选它**。① 工具链已普及：GCC 8+、Clang 6+、MSVC 16.9+、arm-none-eabi-gcc 8+ 全支持；② POSIX 2024 对齐 C17，系统编程天然落在这里；③ 语言层面已是"最新且通用"的稳定态 |
| **C23** | ⚠️ 太新，不适合当基准。2026 年现实：GCC 15 起默认 `-std=gnu23`，Clang 18 默认 gnu17、Clang 20 默认 gnu23，MSVC 支持不完整。线上代码与教学材料仍大量以 C11/C17 为目标 |

### 各标准新增特性一览（挂 B16 的卡）

```
C89/C90  基础语法、stdio、字符串
C99      // 注释、for 内声明、VLA、restrict、inline、_Bool、long long、
         复合字面量、指定初始化器、柔性数组、snprintf、stdint.h、inttypes.h、__func__
C11      _Generic、_Static_assert、_Alignas/_Alignof、_Atomic、_Noreturn、
         _Thread_local、匿名 struct/union、u''/U'' 字面量、char16_t/char32_t
C17      无新语言特性（仅缺陷修订 DR 400/401/402 等）
C23      nullptr、true/false/bool/static_assert 关键字、constexpr/consteval、
         auto 类型推导、typeof/typeof_unqual、#embed、__VA_OPT__、
         二进制字面量 0b1010、数字分隔符 1'000'000、enum 固定底层类型、
         unreachable()、stdckdint.h 检查整数运算、[[属性]]
```
